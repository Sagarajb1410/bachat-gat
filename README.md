# Friends Circle Bachat Gat

The group's savings app: https://sagarajb1410.github.io/bachat-gat/

- `index.html`, `manifest.webmanifest`, `sw.js`, icons: the installable app page (GitHub Pages). It opens the group's Google Apps Script web app full screen.
- `code.gs` and `apps-script/Index.html`: the Apps Script code that runs inside the group's Google Sheet ledger. Copy them into Extensions → Apps Script in the sheet.

All money data and PINs stay in the Google Sheet and Apps Script. Nothing private is stored in this repository.
